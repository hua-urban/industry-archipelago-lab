# 產業共域｜五島探索版

獨立於既有華都更群島的靜態探索站。此倉庫不修改、嵌入或代管既有 A～E 詳細頁；主題連結以整頁跳轉到原網址。

## 本機執行

使用任何靜態伺服器。例如在專案目錄執行 `python3 -m http.server 8786 --bind 127.0.0.1`，開啟 `http://127.0.0.1:8786/`。沒有 npm 安裝、建置、後端、金鑰或資料庫。

## 維護

- `content.js`：五組摘要、40 個主題、跨組路線與需求篩選。主題 ID 要與原站一致。
- `scene.js`：一個 Three.js renderer、五島造景、連線與相機。
- `app.js`：需求篩選、八主題、整頁跳轉、動態開關及 WebGL 備援。
- `style.css`：版面與手機樣式。
- `CONTENT-AUDIT.md`：內容來源、盤點範圍與待確認事項。

內容是公開原站的獨立快照，不會自動隨原站更新。更新主題時同步檢查原站 ID 和連線兩端；新網站的修改不會回寫原站。字型由 Google Fonts 載入，失敗時使用系統字型。Three.js 以公開原站的既有版本快照提供，MIT 授權見 `lib/THREE-LICENSE.txt`。

## 自然地形版（2026-11-05）

五島沿用原本特色與主題，加入連續草坡、沙岸、淺灘與岸石，以及 A 改建街廓、B 老屋庭院、C 安居灣岸、D 商用港區、E 綠色園區的造景細節。水波、岸邊浪花、航船與屋頂風扇在一般模式運行；減少動態時停止環境動畫與自動導覽。此為自然地形版當時設計；本版手機改為固定相機，保留縱向捲動。手機初次建立場景時減少植栽密度，使用單一 renderer 並限制 DPR。

標籤與主題內容依然由原有資料提供，沒有新增成員或合作實績。`canvas` 的 `data-render-metrics` 提供本機渲染觀測，僅表示該瀏覽器當次表現。

## 部署與回復

GitHub Pages 發布 `main` 分支根目錄；不使用原官網部署流程，不設定 CNAME，不改 DNS。回復時在此倉庫 revert 指定提交再推送。若要下架，只關閉此倉庫 Pages，不處理既有官網。

發布前以瀏覽器檢查：五島標籤、需求篩選、14 條路線、40 個主題、整頁跳轉、導覽與減少動態、手機寬度、WebGL 備援。瀏覽器手機模擬不等於實機效能測試。

## 需求接棒版（2026-11-11）

保留 5 島、40 主題、14 條既有路線；以一條需求為單位照亮兩座島，光點沿航線移動。分類篩選、上一條／下一條與路線預覽控制同一狀態。接棒示意表達可討論的連結，不是即時轉介紀錄。

五組簡報的定位整理進 `content.js` 與 `identities`；各組介紹分別呈現地主信任與共識、房源水平與垂直接續、高齡安居電梯案、每案主責、房產客戶成長構想。五種造景是概念轉譯。

手機初次載入減少植栽，所有裝置關閉即時陰影，DPR 上限 1.25；桌面上限 1.5。手機保持相機固定，讓標籤穩定並保留縱向捲動；桌面採小幅來回轉動。停止海域動態會暫停波紋、船、風扇及需求光點；減少動態模式保留靜態資訊與可點選入口。瀏覽器分頁不可見或畫面離開海域時略過渲染。

## 放大群島與互航版（2026-11-11）

手機五島模型比例由 0.65 調為 0.83，兩側島位略拉開；相同 390px 視窗的實際地形投影寬度增加約 28%。桌面模型比例增為 1.2。標籤、主題與各組網址保持原入口行為。

海域常駐五段既有跨組主題構成的連通航道（A–B、B–D、C–D、C–E、A–E），作為低對比底網；不是同時鋪滿所有路線。選定需求另顯示一條金色接棒航道、雙向箭頭、港口圈與醒目小船。三艘背景船在既有航道間往返，方向錯開；一艘需求船沿目前航道接棒。船首依曲線切線轉向，尾流固定在船尾。停動態會讓全部船與港口圈停止，減少動態時保留靜態船、箭頭與航道。

船使用共享幾何與材質，不加入後製特效。港口留出船身空間，長對角線繞開中央島；航道與船是協作關係的視覺示意，不代表即時交通、真實場地或正在發生的轉介。
