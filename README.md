# 產業共域｜五島探索版

獨立於既有華都更群島的靜態探索站。此倉庫不修改、嵌入或代管既有 A～E 詳細頁；主題連結以整頁跳轉到原網址。

## 本機執行

使用任何靜態伺服器。例如在專案目錄執行 `python3 -m http.server 8786 --bind 127.0.0.1`，開啟 `http://127.0.0.1:8786/`。沒有 npm 安裝、建置、後端、金鑰或資料庫。

## 維護

- `content.js`：五組摘要、40 個主題、跨組路線與需求篩選。主題 ID 要與原站一致。
- `scene.js`：一個 Three.js renderer、五島造景、連線與相機。
- `app.js`：需求篩選、八主題、整頁跳轉、動態開關及 WebGL 備援。
- `style.css`：版面與手機樣式。
- `CONTENT-AUDIT.md`：內容來源、盤點範圍與待確認事項。

內容是公開原站的獨立快照，不會自動隨原站更新。更新主題時同步檢查原站 ID 和連線兩端；新網站的修改不會回寫原站。字型由 Google Fonts 載入，失敗時使用系統字型。Three.js 以公開原站的既有版本快照提供，MIT 授權見 `lib/THREE-LICENSE.txt`。

## 部署與回復

GitHub Pages 發布 `main` 分支根目錄；不使用原官網部署流程，不設定 CNAME，不改 DNS。回復時在此倉庫 revert 指定提交再推送。若要下架，只關閉此倉庫 Pages，不處理既有官網。

發布前以瀏覽器檢查：五島標籤、需求篩選、14 條路線、40 個主題、整頁跳轉、導覽與減少動態、手機寬度、WebGL 備援。瀏覽器手機模擬不等於實機效能測試。
